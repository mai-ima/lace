# 自動テスト

```
node tools/test/run.js              # すべて（golden・不変条件・オープンワールド・メニュー）
node tools/test/run.js golden       # 一部だけ
node tools/test/run.js --update     # 基準値（golden/*.json）を作り直す（意図した変更のときだけ）
```

- 乱数と時計を固定して走らせるので、同じコードなら同じ結果になります。
- `golden`: 13 モード × 代表コース × 3 車種を自動運転で 40 秒走らせ、0.5 秒ごとの状態と結果を記録して基準値と比べます。
- `invariants`: NaN が出ないこと、位置と走行距離が合うこと、共有のコース仕様を書き換えないことを確かめます。
- `world`: オープンワールドの交差点で、ウインカーとナビのとおりに出口が選ばれるか、先読みの作り直しが 1 回までかを確かめます。
- `menus`: メニューを巡回し、例外が出ないことを確かめます。
- `w3`: 3D 自由走行（world3d.html を内蔵の http サーバーで開く）。例外、描画予算（中: 300 回・150 万三角形）、信号の矛盾、主要道の見えない壁。
- 車両物理は `node tools/test/phys.mjs`（ブラウザ不要）。
- 失敗すると終了コード 1 を返します。
