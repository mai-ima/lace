# TENRYU RACING

ブラウザで遊ぶ、ストーリーつきのレースゲームです。
ビルド不要・依存ゼロ。HTML / CSS / JavaScript だけでできています。
`index.html` を開くと、そのままレースが始まります（ターミナル画面はありません）。

## 遊ぶ

メニューは矢印キー（または W/A/S/D）と Enter、またはクリック／タップで選びます。
レース中は ↑↓←→ で運転、Esc または P でポーズ、V は 3D 表示用ですが、3D の開発は一時停止中です。

**TENRYU RACING の中身**

- **ストーリー 4 本＋サブストーリー（マルチエンディング）** 本編「天竜の白い亡霊」（番外編・後日談つき）／ストーリー2「湾岸 1989」（刑事 or 記者の二つのルート、6 つの結末）／ストーリー3「六連星」（2002 年・群馬の走り屋、合法 or 地下のルート、6 つの結末）／ストーリー4「グリッドの向こうの夏」（中学三年と高校生のカート部、選択で 6 つの結末）。章タイトル・背景・表情つき立ち絵・揺れ／フラッシュ／集中線／擬音・VS 画面・選択肢の演出、レース中の無線、SP バトル。**管理者モード**（タイトルの「管理者モード」／ブリーフ画面／レース中 `o`・`F2`／ポーズメニュー）でバトルのスキップや各種数値の変更が可能（保存されず、リセットで初期値に戻る）
- **オープンワールド** 浜松市の主要道路と地区（37 地点・50 路線）〜東名／新東名〜名古屋市。信号交差点（右左折・交差車両）、左側通行と対向車、パトカーの追跡、オービス
- **アルバイト** タクシー・宅配便（こわれもの）・うなぎ弁当の出前
- **デイリーレース** 日付で決まる全員共通のコース・天気・周回。表彰台で連続日数とボーナス
- **実績** 27 種のトロフィーを解除すると賞金
- **グランプリ** 8 カップ（峠キング決定戦、公道 GP 箱根シリーズ、GT サーキットなど）
- **峠バトル** ガードレールの狭いダウンヒルで 1 対 1（後追いスタート・150m 引き離しで勝ち）
- **チャレンジ** エリミネーション／デュエル／アーケード／ポリスチェイス／ハイウェイ・サバイバル、**タイムアタック**（ゴースト）
- **ミニゲーム** ジムカーナ・ゼロヨン（手動シフト）・ピタッと停止
- **カジュアル** パーティレース・コインラッシュ（コインと加速パネルはここだけ）
- **コース 23 本**（峠 5 本・サーキット・高速道路・ご当地コースを含む）、**車 36 台**（AE86・FC/FD・R32 系などのモチーフ車、スーパーカー、ゴーカートやトラクターなどのお遊び車両）
- **音** 車種ごとに合成したエンジン音（直 3／直 4／直 6／水平対向／ロータリー／V8／V12／ディーゼル／2 ストローク／電気）、自動変速、ターボとブローオフ、スキール、風切り、雨音
- 天気（雨・雪・霧・砂嵐・降灰）、トンネル、ミラー（左右反転）コース、改造と塗装
- **3D 表示（試験版）** 設定またはレース中の `v` キーで WebGL（three.js）の立体描画に切り替え。標準は疑似 3D

操作: `←` `→` ハンドル、`↑` アクセル、`↓` ブレーキ、スペースでニトロ（ゼロヨンではシフトアップ）、`p` 一時停止。


操作は共通で、矢印キー（または `hjkl`）で動かし、`q` でやめます。
テトリスは `↑` 回転・スペースでハードドロップ・`c` でホールド・`p` で一時停止、
ローグライクは `y u b n` で斜め移動・`p` で薬・`.` で待機です。
スマートフォンでは画面の中に方向キーが出ます。

ローグライクの記号は `@` あなた、`#` 壁、`>` 下り階段、`!` 薬、`$` 金貨、
`)` `[` 装備、`*` 護符。アルファベットはすべてモンスターで、深いほど強くなります。

## アルバム

メインメニューの「アルバム」で、ゲームの曲 12 曲を順に聴けます。曲を選ぶと流れ、終わると次の曲へ進みます（くり返しは「全曲／この曲／なし」）。

## 背景と表情

- 会話の背景は、コースの絵のほかに、SVG で描いた場面が 12 種あります（校舎の坂道・教室・峠の茶屋・整備工場・駅のホーム・病院の廊下・屋上・神社の参道・夜祭り・自室の夜・海辺の夕暮れ・カート場のピット・夜の湾岸）。台本では `{ bg: 'school' }` のように名前で指定します。
- 表情は 17 種（`smile` `cool` `sad` `shock` `angry` に加えて `laugh` `worry` `blush` `cry` `think` `sleepy` `wink` `smug` `determined` `panic` `tired` `gentle`）。台詞の言い回しからも自動で細かい表情を選びます。
- 画面のアイコンはすべて SVG です（絵文字は使いません）。

## 管理者モード

バトルのスキップや、速度・加速・グリップ・交通量・制限時間などの数値を変えられます。
設定は保存されず、リセットで初期値に戻ります。
開く場所: タイトルの「管理者モード」、バトルの準備画面、レース中の `O` / `F2`、ポーズメニュー。

## かくし機能「ひみつの遊び場」

昔のミニゲームと道具を、すべてウィンドウとボタンの GUI にして隠してあります。
開き方は 3 つ（ヒントは README だけ）:

- キーボードで ↑ ↑ ↓ ↓ ← → ← → B A
- タイトルのロゴを 7 回続けてクリック／タップ
- URL の末尾に `#hidden` を付けて開く

中身: テトリス・スネーク・2048・マインスイーパ・倉庫番・ローグライク／数当て・三目並べ・じゃんけん・言葉当て・ブラックジャック・レース・クイズ／ドット絵・電卓・設定（言語・音・文字の大きさ・記録の消去）。

## 動かし方

### 1. HTML としてそのまま開く

`index.html` をブラウザで開くだけです。

### 2. サーバーで開く

```sh
python3 -m http.server 8000
# → http://localhost:8000
```

### 3. Vercel などに置く

ビルドは不要です。このフォルダをそのままデプロイしてください（`vercel.json` つき）。

## ファイル構成

```
index.html                  ランディング（レースを閉じたときの画面）と読み込み
assets/css/tui.css          画面の見た目（レース、会話、ウィンドウ、ひみつの遊び場）
assets/js/core.js           言語・保存・キー入力の土台
assets/js/start.js          起動（レースを自動で開く）
assets/js/race-data.js      コース・車・ドライバー・保存・実績
assets/js/race-engine.js    走る・描く（疑似 3D）
assets/js/race-3d.js        WebGL の 3D 描画
assets/js/race-front.js     メニュー・物語の会話・管理者モード
assets/js/race-story*.js    ストーリー（本編 / 2 / 3 / 4 / 5 ほか）
assets/js/hub.js            ひみつの遊び場
assets/js/games*.js         ミニゲーム（キー操作／ボタン操作）
assets/js/gui.js            ウィンドウ・効果音・設定・ドット絵・電卓
```

## 対応環境
