# 道路・交通の仕様表（公式の値とゲームの値）

- ゲームで使う値の実体は `assets/js/race-spec.js` の `R.SPEC` にある。値を変えるときは、この表も一緒に直す。
- 「区分」の意味:
  - 一次: 法令・官公庁・NEXCO の資料
  - 学会: 交通工学研究会（JSTE）の資料
  - 二次: まとめ記事など、一次資料で確かめていないもの
  - 推定: 資料がなく、ゲームの側で決めた値

## 高さの基準
- PLATEAU の 3D Tiles は楕円体高（日本のジオイド 2011 で換算）。
- 地理院 DEM は標高。浜松のジオイド高は約 39.6〜40.1m なので、DEM の値にこれを足すと PLATEAU と合う。
- 出典（一次）: PLATEAU 可視化用データ変換仕様、地理院 測量計算 API。
