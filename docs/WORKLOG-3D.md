## 確認の手順
- テスト: `node tools/test/run.js`（golden・invariants・world・menus・w3）と `node tools/test/phys.mjs`。
  w3 の予算は、中画質で描画 300 回以下・三角形 150 万以下。renderer.info は影の描画も数えるので、影を落とす物は 2 倍になる。
- コンテナが再起動したら、ローカルのサーバーを立て直す: `cd /home/user/lace && nohup python3 -m http.server 8123 &`
- 作業用のスクリプト（スクラッチパッド）
  - street.js: 路上視点（POSES・OUT・Q・TIER）
  - cmp.js: 真上から（PTS・OUT・HALF）
  - orthocrop.py: 航空写真の切り抜き
  - dbg2.js: EXPR を評価する
  - tribreak.js: 三角形の内訳
- データを作り直す道具: tools/world/ にある。
  - build_center.py・build_tran.py・dump_net.mjs: 道路網
  - build_water.py: 川
  - dem_bldg.py: 標高に残った建物の塊を除く
  - photo_cross.py: 写真から横断歩道を補う
  - build_parking.py: 駐車場（区画の中心と奥の向き・出入口・種類も出す）
  - build_stops.py: バス停（OSM）
  - vehicles.mjs: 車
- 座標: x が東、z が南。LAT0 = 34.7037、LON0 = 137.7351。
- 描画回数の内訳を調べる: scratchpad の calls.expr（renderBufferDirect を包んで数える）を dbg2.js で（VW=960 VH=600 EXPR="$(cat calls.expr)"）。三角形は tri.expr。
- 近くで見る: scratchpad の look.js（TARGETS=[[x,z,手前m,向きのずれ度]]、道路の上から）、freecam.js（CAMS=[[目x,高さ,目z,先x,先高さ,先z,fov]]、車を隠す）。

## 済んだこと（直近）
- 車輪: cars.js の extractWheels で、名前に頼らず形で切り出す（4 隅の円い塊がタイヤ。トー角は直す）。確認は tools/world/wheelview.html。
- 車の LOD（tools/world/vehicles.mjs）
  - sloppy は使わない。法線も考えた間引き（simplifyWithAttributes、実寸の誤差）を使う。
  - 面ごとに頂点が分かれたモデルは、位置で頂点をまとめてから滑らかな法線を作る（lod2、lod1 のテクスチャの無い部品）。
  - 面の向きがそろっていないモデル（レクサス ES・アコード 2019）は、この方法で壊れるので採用しない。
- ガレージ: assets/js/w3/garage.js（C キー・一時停止画面）。写真は assets/data/world/cars/thumb_<key>.jpg（scratchpad の thumbs.js で作る）。
- 平面駐車場: build_parking.py（OSM と PLATEAU 土地利用）。道路の上の屋根: bldg_over.py（柱つき）。
- 橋の端の高さは道路に合わせる（world.js の最初）。標高に残った建物の塊は dem_bldg.py で除く。
- 描画回数の削減（見た目は同じ）: 建物と地形の 200m のまとまりは、遠く（260m 以上）で 4 つとも画面に入っているときだけ 400m にまとめて描く（world.js の lodMerge・out.update。app.js の present() から毎回呼ぶ）。
  標識は 450m 以内だけを並べる。最悪の地点で 289 → 237 回。
- バス停・駐車場の設備: assets/js/w3/street.js
  - バス停（stops.json の 98 か所）: 一番近い道路の歩道の縁に標識柱（丸い板に停留所名・時刻表・置き台）。板は近づくバスの方を向く（左側通行）。
    上屋（屋根・柱・ガラス・ベンチ）は OSM の shelter か、幅 3.2m 以上の歩道の大きな道路（rank 3 以下）の 75%。ベンチは OSM の bench。
  - 駐車場: 全区画に車止め（有料は全部、ほかは 6 割）。kind 1 はロック板と精算機、kind 2 はゲート（島・発券機・精算機・開閉バー。車が 9m 以内に来るとバーが上がる）。
    有料の出入口に P の看板。kind は OSM の fee・access、無ければ駅からの距離で割合を決めた推定。
  - 板の絵は標識の画像（4096 × 3584）の下の 512 と方面案内の空きに描く（描画は増えない）。小物は材質ごとのインスタンス描画で、カメラの周りだけ並べる。
- 駐車場の判定（build_parking.py）: OSM と重ならない（土地利用だけが根拠の）所は、航空写真の色で緑（2G−R−B が大きい）・土（赤茶）が多ければ除く（5 か所）。
  写真に区画の線が見えない土地利用だけの所は、線と車止めを推測で描かない（37 か所）。OSM の surface が未舗装なら砂利の色・線なし。
  店（OSM の shop・飲食・給油所などが 25m 以内、または access=customers）の駐車場は無料（ゲートなし、車止めあり）。写真は全体に青緑の色かぶりがあるので、灰色の判定に色の差を使わない。
- 止まっている車: assets/js/w3/parked.js。区画の 45〜65% に、7 割はバックで止める。形は _lod3.glb（tools/world/car_lod3.mjs で lod2 から作る。部品の縁は固定しないと穴が開く）。
  画質ごとに範囲と台数（中 90m・10 台、高 160m・48 台、超高 400m・400 台で lod2）。当たり判定あり。
- 画質「超高」（?tier=ultra、一時停止画面の「画質」ボタンで選んで保存）: 予算を考えず最大（MSAA 8 倍・影 8192 で ±220m・描画 4km・一般車 90 台（細かい形 24 台）・電柱と街灯と電線と標識と小物を遠くまで）。gfx.hi は高と超高、gfx.ultra は超高。
