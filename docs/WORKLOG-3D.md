  - photo_cross.py: 写真から横断歩道を補う
  - build_parking.py: 駐車場（区画の中心と奥の向き・出入口・種類も出す）
  - build_stops.py: バス停（OSM）
  - vehicles.mjs: 車
- 座標: x が東、z が南。LAT0 = 34.7037、LON0 = 137.7351。
- 高画質の航空写真: VIRTUAL SHIZUOKA の航空レーザのオルソ（1 画素 20cm、CC BY 4.0）。tools/world/vs_ortho.py で /tmp/world/vs_ortho に 63 図郭（ゲームの範囲）を集める。
  読むのは tools/world/vsimg.py（ゲームの座標 → 平面直角座標系 第 8 系 → 画素。pyproj が要る: pip install pyproj scipy opencv-python-headless）。
- 路面表示の読み取り: tools/world/road_marks.py → road_marks.bin（写真の白・黄の塗装を、車道の中でトップハット変換で取り出し、線・長方形・穴あきの形に分ける。木の葉・車・小さな塊は除く）。
  - 描画は assets/js/w3/marks.js（100m のまとまりを 200m ごとに 1 つの形に。描く距離は 低 250m・中 350m・高 700m・超高 すべて）。色: 0 白・1 黄・2 赤の色付き舗装・3 緑・4 青（自転車の矢羽根）。
  - 車載写真レーザ測量（MMS）の点群: 浜松の中心部は 2021 年の 3 図郭（08OC7243・7253・7263。西側の南北の幹線 x≈−740〜−600、z −1330〜−650 の約 700m）だけ（2019・2020 年の MMS に浜松は無い）。
    tools/world/mms_raster.py で /tmp/world/mms/*.las を 10cm の格子（反射強度・点の色）にまとめ、road_marks.py が点のある所では点群で読む。
    - 路面の点は「地面の分類 2」だけでなく「分類 6」にも多く入っている → 1m ごとの路面の高さ（分類 2 の平均を双一次補間）から ±7cm の点を使う。
    - 升ごとに点のいちばん多い計測の時間帯（1 秒）だけで平均する（別の回の遠い走査が混ざると模様が出る）。
    - 反射強度は材質・回で水準が変わるので、対数にして周りとの比で見る（白 2.2 倍以上、黄・橙は反射が弱いので 1.4 倍以上で点の色が周りより橙）。
    - 橙に写る塗料は、写真の色（緑 − 青）で黄（数字・線）と赤（減速マーク）に分ける。点群には車が無いので、車の大きさの塊を除く判定はしない。
    - 写真とのずれは 0.13m 以下（位相相関で確認）。
  - 信号機: 灯器は外部の日本の信号機（フード付き横型 3 灯）、歩行者用の灯器を柱に追加（その進入路を渡る人の向き、車両の赤で青）。
    点灯は加算で重ねる（消灯はレンズの絵が見える）。細かい形はカメラの近く（中 150m・高 400m・超高すべて）だけ、遠くは箱。描画 243 回・143 万三角形。
  - 中の島（中央分離帯・交通島）: build_tran.py の 3 段目。道路の外の縁に接しない「歩道」は、地理院の道路構成線（RdCompt 2411・2401）で
    囲まれた所、または 2 本の線に挟まれた帯（間隔 3.2m まで。端の開いた細長い分離帯）だけを島にする。それ以外は、写真が道路に見え
    （暗い無彩色 4 割以上・白と合わせて 6 割以上）線路（RailCL・RailTrCL）に重ならなければ車道に戻す。
    導流帯（「く」の字の塗装）や車線の上に置かれていた一段高い島（約 2,900m²）が平らな車道になった。車線の幅の測定には導流帯を含めない。
  - 歩道: OSM の独立した歩道の線（footway=sidewalk、ゲームの範囲に 360 本）が通る所は、歩道の無い区分の道を太らせた分でも歩道にする
    （10m ごとに分け、写真がアスファルトに見える所は車道のまま。OSM の線の位置ずれで車線を歩道にしないため）。約 3,000m²。
  - 残り（#30）: OSM で歩道の無い区分（unclassified 以下）でも幅の広い道（例: 駅前の一方通行 4 車線、way 167997575）は、半幅 + 4m で太らせるため
    タイル舗装の歩道まで車道になり、歩道の模様の粒が路面表示として出る。幅の広い道は太らせる量を減らし、写真で歩道（タイル・明るい舗装）を見分ける。
  - 写真の青緑（矢羽根）と赤（減速マーク・色付き舗装）は、影の青み・隣どうしのつながりを避けるため、周り 3m の色との差で見る・穴だけを埋める。
  - 車線の位置（marks.js の fitLanes）: 道の 15〜85% の区間の縦の線（破線・実線・細長い形の主軸。幅 0.3m の矢印の軸は除く）を道に投げ、長さの重みで横のずれを集めて山を探す。
    山の間が 2.4〜4.3m の所を車線にし、e.lanes = { f, b } に入れる。一般車（traffic.js の nLanes・laneOffE）はこれを使う。線の上を走る一般車の割合が 13.4% → 5.9% に減った。
  - 交通島（縁石の島）は、写真の島の中がアスファルトと同じ色の所が多く、明るさでは分けられない。縁石の段（影）を手がかりにする方法を後で考える。
- 描画回数の内訳を調べる: scratchpad の calls.expr（renderBufferDirect を包んで数える）を dbg2.js で（VW=960 VH=600 EXPR="$(cat calls.expr)"）。三角形は tri.expr。
- 近くで見る: scratchpad の look.js（TARGETS=[[x,z,手前m,向きのずれ度]]、道路の上から）、freecam.js（CAMS=[[目x,高さ,目z,先x,先高さ,先z,fov]]、車を隠す）。
